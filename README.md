# Ethan S · Portafolio

Next.js 15 + TypeScript + GSAP + Lenis + Three.js.

## Comandos
npm install
npm run dev        # http://localhost:3000
npm run lint
npm run typecheck
npm run build

## Dónde editar
- src/data/site.ts      -> nombre, WhatsApp, mensaje predeterminado
- src/data/projects.ts  -> proyectos (nombre, categoría, url, rol y texto del caso)
- public/proyectos/     -> capturas propias (ver LEEME.txt)
